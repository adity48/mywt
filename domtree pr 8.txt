    <div id="container"></div>

    <script>
        function changeText() {
            document.getElementById("text").textContent = "Text Changed Successfully!";
        }

        function addElement() {
            let p = document.createElement("p");
            p.textContent = "New Element Added Successfully!";
            p.id = "newElement";

            document.getElementById("container").appendChild(p);
        }

        function removeElement() {
            let p = document.getElementById("newElement");

            if (p != null) {
                p.remove();
            } else {
                alert("No element to remove!");
            }
        }
    </script>

Theory & Concepts
3.1 JavaScript Objects
An object in JavaScript is a collection of properties and methods.
•	Properties store data.
•	Methods are functions associated with an object that perform actions.
Example:
const calculator = {
    num1: 10,
    num2: 5,

    add() {
        return this.num1 + this.num2;
    }
};
Here:
•	num1 and num2 are properties.
•	add() is a method.
•	this refers to the current calculator object.
________________________________________
3.2 Object Properties
Properties represent values associated with an object.
Example:
num1: 10,
num2: 5
The calculator uses these properties as input values for its operations.
