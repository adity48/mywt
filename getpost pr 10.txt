Objective
To understand how HTML forms communicate with Java Servlets. 
1.	To handle GET and POST requests in a servlet. 
2.	To read form data using request.getParameter(). 
3.	To display the submitted form data dynamically in the response. 
4.	To understand the use of HttpServletRequest and HttpServletResponse. 
5.	To develop a simple form-based web application using Servlet.

Problem Statement:
           Build a Java Servlet that handles form parameters submitted using GET and POST methods.
The application should:
•	Create an HTML form to accept student details. 
•	Send the form data using GET or POST. 
•	Read the submitted values using request.getParameter(). 
•	Display the submitted information dynamically in the servlet response.

Theory & Concepts
3.1 HTML Form
An HTML form is used to collect information from the user.
Example:
<form action="StudentServlet" method="post">
•	action specifies the servlet URL. 
•	method specifies how the data is sent. 
•	GET sends data through the URL. 
•	POST sends data in the request body. 
________________________________________
3.2 GET Method
The GET method sends form data as part of the URL.
Example:
StudentServlet?name=Rahul&course=BCA
GET is commonly used when retrieving or requesting information.
________________________________________
3.3 POST Method
The POST method sends form data in the HTTP request body.
It is commonly used for submitting forms and sending data that should not appear in the URL.
________________________________________
3.4 request.getParameter()
The getParameter() method is used to retrieve a form value.
Example:
String name = request.getParameter("name");
If the form contains:
<input type="text" name="name">
then getParameter("name") retrieves the entered value.
________________________________________
3.5 HttpServletRequest
HttpServletRequest represents the request received from the client.
It provides methods to:
•	Read form parameters 
•	Access request information 
•	Read HTTP headers 
________________________________________
3.6 HttpServletResponse
HttpServletResponse is used to send a response back to the browser.
